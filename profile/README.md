# Forever In Our Hearts

Online memorial websites for people and pets, online funeral notices, and QR code memorials for headstones and
plaques. Families pay once per memorial. Funeral homes publish notices and memorials under their own brand.

- [Online memorials](https://foreverinourhearts.co): US, UK, Canada, Ireland, New Zealand and more
- [Australia](https://foreverinourhearts.com.au)
- [QR code memorials](https://foreverinourhearts.co/qr-code-memorials)
- [Funeral Director Network](https://foreverinourhearts.co/funeral-director-network)

## MCP server

[memorials-mcp-server](https://github.com/Forever-In-Our-Hearts/memorials-mcp-server) is a free, read-only
[MCP](https://modelcontextprotocol.io) server. It lets AI assistants such as Claude and ChatGPT find public memorials,
funeral notices and partner funeral homes, and link to each page.

- Server: `https://mcp.foreverinourhearts.co/mcp`
- How to connect: [foreverinourhearts.co/mcp](https://foreverinourhearts.co/mcp)
